# TechWorld — Electronics E-Commerce Website

TechWorld is a full-stack e-commerce project for browsing electronics and gadgets, with a shopping cart, simulated checkout, and admin dashboard.

## Features
- Responsive frontend using HTML, CSS, and JavaScript
- Backend built with Node.js and Express
- SQLite database for storing orders
- Shopping cart and product listings
- Demo payment options: UPI, Card, and Net Banking
- Simulated payment success and failure
- Admin login and order management dashboard

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite

## Run Locally

1. Install [Node.js](https://nodejs.org/).
2. Open the project folder in VS Code.
3. Open a terminal and navigate to the backend folder:
   ```bash
   cd backend
   npm install
   ```
4. Configure the required environment variables in `backend/.env` using the project's expected variable names.
5. Start the backend:
   ```bash
   node server.js
   ```
6. Open `index.html` in your browser.

## Demo Notice
All payments are simulated for educational and project presentation purposes. No real payment or bank transaction is processed.
